# Submission screenshots

Place the final screenshots in this directory before submitting:

1. `grounded-answer.png` — a successful answer with citation and retrieval evidence.
2. `off-topic-abstention.png` — an unrelated question showing abstention and no citation.
3. `evaluation-results.png` — the expanded evaluation JSON or UI output.
4. `railway-deployment.png` — the live app with the Railway URL visible.

The screenshots should not show API keys, private Railway settings, or personal account information.
